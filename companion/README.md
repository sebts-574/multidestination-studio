# Companion module for Multidestination Studio

- `obs-studio-4.0.0-multidestination.2.tgz`: the Bitfocus Companion **OBS Studio** module with the
  **Multidestination Studio** presets, ready to import in Companion. It is attached to every
  Multidestination Studio release (and to the build artifacts). User guide:
  [docs/companion-module.md](../docs/companion-module.md).
- `multidestination-studio.patch` and `UPSTREAM_COMMIT`: the source of this module (changes to
  `bitfocus/companion-module-obs-studio` at that commit), kept to rebuild or update it later.
