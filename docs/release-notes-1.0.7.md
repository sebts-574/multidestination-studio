# Multidestination Studio 1.0.7

## Changed
- **Drag to move, from any row.** In the Scenes and Sources lists, pressing on a scene or source and dragging moves it, whether it was selected or not. To select several rows by dragging, start from an empty area of the list. Ctrl + click (Cmd + click on macOS) and Shift + click still select.

## Fixed
- **A scene folder can no longer be taken live by mistake.** When a folder is selected in the Scenes list, Transition and Cut are disabled and a short note explains that folders only organise the list and that a scene must be selected.
