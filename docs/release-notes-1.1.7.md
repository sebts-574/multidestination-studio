# Multidestination Studio 1.1.7

## macOS: output screens
- Output windows now stay on their screen on every Space: an app switching to full screen, or switching between the studio and the OBS window, no longer hides them or makes them slide.
- They cover the whole screen, menu bar and Dock included, without needing “Displays have separate Spaces”.
- Windows and Linux are unchanged.

## Texts
- The Cues setting describes the current behaviour: the first scene uses the transition that starts the cue, Auto-follow, and running a cue with Transition or a quick transition.
- The Output blending hint mentions the aspect ratio lock (Shift does the opposite).

## Companion
- Module: `obs-studio-4.0.0-multidestination.3.tgz` (unchanged since 1.1.6's update).

## Installation
- **Windows 10/11**: `multidestination-studio-1.1.7-windows-x64-installer.exe` (not code-signed: SmartScreen may ask for confirmation).
- **macOS**: universal `.pkg` (not signed: System Settings → Privacy & Security → Open Anyway).
- **Ubuntu 24.04**: `multidestination-studio-1.1.7-x86_64-linux-gnu.deb` (`sudo apt install ./multidestination-studio-1.1.7-x86_64-linux-gnu.deb`).
- **User guide (PDF)**: [Multidestination-Studio-1.2.1-User-Guide.pdf](https://github.com/sebts-574/multidestination-studio/blob/main/docs/Multidestination-Studio-1.2.1-User-Guide.pdf) (latest guide).

Close OBS before installing. Requires OBS Studio 31.1 or later.
